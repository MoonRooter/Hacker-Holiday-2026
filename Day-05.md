# 🎄 Day 05 – Beach Bar Jukebox

## 📖 Overview

Day 05 focuses on a Boot2Root challenge where the objective is to compromise a vulnerable web application, gain initial access to the target machine, and escalate privileges to obtain the root flag.

## 🎯 Objectives

- Perform reconnaissance on the target.
- Identify and exploit the vulnerable service.
- Gain initial access to the machine.
- Escalate privileges to root.
- Retrieve both the user and root flags.

## 🛠️ Skills Practiced

- 🌐 Web Enumeration
- 🔍 Service Enumeration
- 💥 Exploitation
- 🐧 Linux Privilege Escalation
- 🔑 Boot2Root
- 💻 Command Line

## 🧰 Tools Used

- Nmap
- Gobuster / FFUF
- Burp Suite
- Netcat
- SSH
- LinPEAS
- Linux Terminal

## 📚 Key Takeaways

- Improved reconnaissance and enumeration techniques.
- Learned how to identify and exploit vulnerable services.
- Practiced Linux privilege escalation methodologies.
- Reinforced the importance of proper system hardening.
