# 🎄 Day 04 – Complimentary

## 📖 Overview

Day 04 explores cloud security by analyzing a web application that grants "complimentary" access without authentication. The challenge focuses on identifying how the application obtains cloud credentials and assessing the risks of improperly configured cloud resources.

## 🎯 Objectives

- Investigate the application's authentication mechanism.
- Identify how AWS credentials are obtained.
- Access and analyze exposed cloud resources.
- Retrieve the challenge flag.

## 🛠️ Skills Practiced

- ☁️ Cloud Security
- 🔑 AWS IAM
- 🪣 Amazon S3
- 🗄️ Amazon DynamoDB
- 🔍 Cloud Enumeration
- ⚠️ IAM Misconfigurations

## 🧰 Tools Used

- AWS CLI
- Web Browser
- Browser Developer Tools
- cURL

## 📚 Key Takeaways

- Learned how cloud applications authenticate users and services.
- Explored AWS resource enumeration techniques.
- Understood the risks of exposed or overly permissive IAM credentials.
- Gained practical experience interacting with AWS services securely.
